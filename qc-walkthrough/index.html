Property Walkthrough Help

Getting Started

Select a property to begin. Add items to each room as you walk through, then mark each item Pass or Flagged.

Item Actions

  • ✓ Pass — Acceptable condition, no action.
  • ⚠ Flag — Needs attention. Opens detail panel for condition, notes, and assignment.
  • 📷 Photo — Camera opens. Photo stored immediately to device storage.
  • 🎤 Voice — Tap to record, tap again to stop. Transcribed live if browser supports it.

Condition Types

  • Needs Repair — Damaged or broken.
  • Replace — Full replacement needed.
  • Missing — Not present at property.
  • Dirty/Needs Cleaning — Needs cleaning.
  • Need to Order — Out of stock, needs restocking.
  • Other — Add details in notes.

Assignments

  • Manager — Operations manager handles it.
  • Cleaner — Cleaning team on next turnover.
  • Contractor — Skilled trade required.
  • Landscaper — Outdoor/yard maintenance.

Adding Items

Tap + Add Item in any room. Rooms start empty — you add items as you walk through.

Storage & Sync

All data (photos, audio, notes) is stored on your device using IndexedDB — survives browser restarts, crashes, and battery loss. The sync indicator shows upload status. Use Export Package on the summary screen as a fallback if server sync doesn't work.
